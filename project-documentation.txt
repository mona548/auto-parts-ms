اسم المشروع: نظام إدارة قطع الغيار (Parts Management System)
نوع المشروع: تطبيق ويب ديسكتوب

الألوان الرئيسية: أزرق (#3B82F6) وأبيض (#FFFFFF)

   📦 الوظائف:
   • عرض جميع قطع الغيار في جدول تفاعلي
   • البحث والفلترة حسب:
     - اسم الصنف
     - الفئة
     - الحالة (متوفر/منخفض/ينفذ)
   • عرض تفاصيل كل قطعة:
     - الكود
     - الاسم
     - الفئة
     - الكمية
     - سعر الشراء

     - أخضر: متوفر
     - برتقالي: منخفض
     - أحمر: ينفذ

3️⃣ إضافة قطع غيار (Add Part) - المسار: "/add-part"
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ➕ النموذج يحتوي على:
   • اسم الصنف (مطلوب)
   • الفئة (قائمة منسدلة + إضافة فئة جديدة)
   • عدد القطع (مطلوب)
   • سعر الشراء (مطلوب)
   • سعر البيع (مطلوب)
   • اسم الشركة الموردة
   • كود المارايه (partCode)
   • الموقع (location)
   • الوصف (description)
   • الحد الأدنى للكمية (minQuantity)

   ✨ ميزات:
   • حساب الإجمالي تلقائياً (عدد القطع × سعر القطعة)
   • حساب الحالة تلقائياً بناءً على الكمية
   • إضافة فئات جديدة مباشرة
   • نموذج مُحسّن مع react-hook-form
   • رسائل نجاح مع Sonner Toast

   • عرض تفاصيل الفاتورة في Dialog

   • ألوان الحالة:

   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   • تعديل الكميات

   • الإجمالي الكلي (محسوب تلقائياً)

   • الخصم (اختياري)
   • ملاحظات (اختياري)

   • عرض ملخص الفاتورة قبل الحفظ

📍 PartsContext.tsx - مركز إدارة البيانات الرئيسي

🔹 واجهة Part (قطعة غيار):
   {
     id: string;              // المعرف الفريد (P001, P002, ...)
     name: string;            // اسم الصنف
     category: string;        // الفئة (فلاتر، فرامل، كهرباء، ...)
     quantity: number;        // عدد القطع
     unitPrice: number;       // سعر القطعة
     costPrice: number;       // سعر الشراء
     sellPrice: number;       // سعر البيع
     supplier: string;        // اسم الشركة الموردة
     status: string;          // الحالة (متوفر/منخفض/ينفذ)
     location?: string;       // موقع التخزين (اختياري)
     description?: string;    // الوصف (اختياري)
     minQuantity?: number;    // الحد الأدنى للكمية (اختياري)
     partCode?: string;       // كود المارايه (اختياري)
   }

🔹 الفئات المتاحة (Categories):
   1. فلاتر
   2. فرامل
   3. كهرباء
   4. إطارات
   5. زيوت
   6. محرك
   7. إكسسوارات

   + إمكانية إضافة فئات جديدة

🔹 البيانات التجريبية (8 قطع غيار):
   1. P001 - فلتر زيت تويوتا كورولا (45 قطعة، 80 ريال)
   2. P002 - فرامل أمامية هيونداي (12 قطعة، 200 ريال) - منخفض
   3. P003 - بطارية 70 أمبير (28 قطعة، 300 ريال)
   4. P004 - إطار ميشلان 185/65 R15 (8 قطع، 500 ريال) - منخفض
   5. P005 - زيت موتور 5W30 شل (67 قطعة، 200 ريال)
   6. P006 - شمعات إشعال نيسان (3 قطع، 45 ريال) - ينفذ
   7. P007 - مساحات زجاج بوش (34 قطعة، 65 ريال)
   8. P008 - سير مكيف هوندا (15 قطعة، 120 ريال)

🔹 الوظائف المتاحة (Functions):
   • addPart() - إضافة قطعة جديدة
   • deletePart(id) - حذف قطعة
   • updatePart(id, data) - تحديث قطعة
   • addCategory(category) - إضافة فئة جديدة

🔹 حساب الحالة التلقائي:
   • ينفذ: الكمية ≤ الحد الأدنى (افتراضي: 5)
   • منخفض: الكمية ≤ (الحد الأدنى × 3)
   • متوفر: الكمية > (الحد الأدنى × 3)
